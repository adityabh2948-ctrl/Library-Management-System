Project Overview

🎯 Objective

Digitize basic library operations and maintain book records in an organized way.

⚙️ Technology

C++ with Object-Oriented Programming and standard library components such as vector and string.

📚 Type

Console-based academic mini project focused on practical OOP implementation.

Key Features

01

Add Books

Add a book using a unique Book ID, title and author.

02

Search

Find books by Book ID or by title.

03

Issue Books

Issue an available book to a student and store the holder's name.

04

Return Books

Return an issued book and update its availability.

05

Validation

Prevent duplicate IDs, invalid choices and incorrect operations.

06

Issue Tracking

Maintain the number of times each book has been issued.

OOP Concepts

Encapsulation

Book data is protected through private members and controlled functions.

Inheritance

The Book class derives common behavior from LibraryItem.

Polymorphism

A virtual displayDetails() function demonstrates runtime polymorphic behavior.

Abstraction

LibraryItem acts as an abstract base class to hide implementation details.

Classes & Objects

Classes organize the design while objects represent books and the library.

STL Vector

A vector is used to maintain the collection of books.
